Mahjong Odyssey — Android project (portrait)

ໂຄງການ Android ນີ້ດັດແປງເກມຈາກຊຸດ Windows ທີ່ໃຫ້ມາ:
- ລັອກໜ້າຈໍເປັນແນວຕັ້ງ (portrait)
- ໃຊ້ Android WebView ເປີດເກມ HTML ແບບ offline
- ເປີດ JavaScript ແລະ DOM storage ເພື່ອຮອງຮັບເກມ/ການບັນທຶກ
- ນຳປຸ່ມອອກແບບ Windows ອອກ; ໃຊ້ປຸ່ມ Back ຂອງ Android
- ຮັກສາຊຸດໄພ້ມາດຕະຖານຊຸດດຽວ ຕາມຕົ້ນສະບັບ

ວິທີສ້າງ APK:
1. ຕິດຕັ້ງ Android Studio ແລະ Android SDK Platform 35.
2. ເປີດໂຟນເດີ MahjongOdyssey ໃນ Android Studio.
3. ລໍຖ້າ Gradle Sync ສຳເລັດ.
4. ເລືອກ Build > Build Bundle(s) / APK(s) > Build APK(s).
5. ໄຟລ໌ APK ຈະຢູ່ທີ່ app/build/outputs/apk/debug/app-debug.apk.

ໝາຍເຫດ: ໄຟລ໌ນີ້ແມ່ນ Android Studio project source ພ້ອມສ້າງ APK; ບໍ່ແມ່ນ APK ທີ່ຄອມໄພລ໌ແລ້ວ.
